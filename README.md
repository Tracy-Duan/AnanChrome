# AnanChrome

Anan 系列的本地 AI 浏览器助手。通过 Edge / Chrome 侧边栏调用本机 llama.cpp 与 本地（需自行配置，该项目内也提供了直接下载链接） 模型。采用参考 llama.cpp Web UI 的黑色极简中文界面，通过单一输入框自动判断你要对话、联网搜索还是总结网页。

普通对话与网页总结在本地完成；使用联网搜索时，搜索词会发送给 Tavily。

## Windows 整合 ZIP（1.5.0）

对外分发使用 `dist/AnanChrome-Windows.zip`：一个 ZIP 内包含 `extension/`、完整 llama.cpp b10630 CPU/CUDA DLL、Windows 自包含运行时、首次安装入口和授权文本。它不是纯浏览器扩展 ZIP；`AnanChrome-extension.zip` 仍是仅供浏览器加载/商店使用的纯扩展包。

接收者完整解压后，双击 `Install-AnanChrome.cmd` 注册一次运行时，在扩展管理页加载 `extension/`，再从设置中点击“下载模型”。受 Chrome/Edge 安全边界限制，单纯打开 ZIP 或加载扩展不能直接执行 EXE；首次注册与加载步骤无法省略。后续打开自动连接/启动服务。

设置页的下载按钮使用同一模型文件的稳定 Hugging Face resolve 地址，而不是带 Expires/Signature 的临时 CDN 链接：HauhauCS/Qwen3.5-9B-Uncensored-HauhauCS-Aggressive/Qwen3.5-9B-Uncensored-HauhauCS-Aggressive-Q4_K_M.gguf，SHA-256 为 `2ca636d9e81d3d23ca9b60c234fe185d30ec082eeba69ce770fdb0c76559a4f5`。后台下载支持 Range 续传、关闭页面后继续、校验后配置，错误可重试；不会中断已经运行的旧模型。下载最终落在 `%LOCALAPPDATA%\AnanChrome\Models`。

构建：`powershell -NoProfile -ExecutionPolicy Bypass -File build-release.ps1 -LlamaDirectory '完整的llama.cpp运行目录'`。必须提供 b10630 Windows x64 的完整 DLL 和 CUDA 依赖，不使用开发者机器上的绝对路径作为用户配置。打包不包含聊天、API 密钥、模型权重、测试夹具或本机配置。

左上角现在是可恢复/删除的历史对话，设置固定在菜单底部。新建对话保留旧记录；开始页的两个快捷卡片已移除。一般窗口历史保存在浏览器本地，无痕窗口仅会话保存。历史包含网页快照，仍限制每个会话最多三个。存储空间不足会明确报错，不静默清除较早对话。

## 功能

| 能力 | 触发方式 |
| --- | --- |
| 对话 | 直接提问，流式输出 |
| 联网搜索 | AI 判断请求需要最新或外部信息时触发 |
| 网页阅读 | AI 判断必须读取当前标签页时触发；也可点“总结当前网页” |
| 网页追问 | 已引用网页与总结共同参与后续对话；支持最多 3 个网页引用 |
| 思考 | 输入框上方的二态开关；开启后自动为简单/复杂问题分配 256/768 个思考 token |

**AI 前置判断**：发送消息后，本地模型会在关闭思考链的情况下进行一次极短分类，同时判断直接对话、联网搜索或读取当前网页，以及问题属于简单还是复杂。开启思考时，简单问题最多使用 256 个思考 token，复杂问题最多使用 768 个；分类阶段不会读取网页。

### 网页会话与记忆（1.4.2）

- 总结网页、普通对话和搜索回答使用同一份会话历史。可以直接问“第二点展开说说”“它的依据是什么”，无需重复粘贴原文。
- 输入框正上方以长胶囊显示已记住的网页，默认堆叠收起，鼠标悬浮或键盘聚焦时展开，离开后收起。直接要求“读一下这个网页”即可读取并记住；也可点“读取当前页”。每条带重新读取和忘记按钮。常驻记忆说明和底部空输入提示已移除，长度节选信息可悬浮查看记忆计数，连接错误仍保留提示。
- 最多记住 3 页，成功读取第 4 个不同网页时自动忘记最先加入的一页（先进先出）。重复读取同一 URL 只更新内容，不占新位置，也不改变加入顺序。读取失败不会清除现有记忆。
- 忘记网页后，原文及曾携带该页资料的历史轮次不再发送给生成模型或前置分类器，避免旧摘要又把遗忘信息带回来；旧聊天记录仍在界面上可见。“新建对话”开始一个空会话，旧会话保留在历史列表。
- 切换标签页不会自动读取新网页或替换引用。要讨论新页，明确要求读取当前新页即可。侧边栏直接调用浏览器标签页和脚本接口，不依赖后台消息响应；支持回调和 Promise 两种返回方式。发送时锁定目标标签页，读取前后检查地址，避免模型判断期间切页导致读错页面；异常保留真实原因，不再吞掉错误并一律显示“没有找到发送时的活动网页”。
- 当前会话指针按浏览器窗口隔离，以 `chrome.storage.session` 暂存；一般窗口的历史档案另存于 `chrome.storage.local`，浏览器退出后可从菜单恢复。无痕会话不会写入持久存储。未完成的流式回复不保证恢复。
- 本地 9B 模型暂支持同时引用 3 页，每页缓存最多约 12,000 字符。每次发送按真实模型模板和分词结果检查上下文窗口，最多携带最近 12 条消息；长资料优先节选，必要时减少较早对话，并显示提示。节选不会改变缓存快照；资料未包含的细节不能保证回答，不是无限记忆或全文检索。
- 前置分类结合最近对话、引用标题/地址和活动页标题/地址，不读取网页正文；只有添加、刷新或请求被判定需要读取时才获取正文。网页内容仍视为不可信参考资料，不作为系统命令。

这版参考 Gemini 侧边栏的“持续对话 + 管理网页引用”体验，不包含 Google 账号集成、自动浏览操作或后台自动读取所有标签页。

验证：`node --test tests/*.test.cjs`；本地服务已启动时运行 `node tests/local-context-smoke.cjs`，检查跨标签追问、话题切换和上下文长度。`node tests/preview-server.cjs` 提供合成网页的 UI 测试环境（8094 端口，仅回环访问，浏览器接口为模拟接口，生成使用本地模型）；测试文件不会打包到扩展中。

## 文件结构

### 思考语言与正文分离

思考模式默认引导模型用简体中文分析，最终回答默认中文；英文翻译、代码和原文引用不会被过滤。除系统语言约束外，使用 llama.cpp 的 `continue_final_message: "reasoning_content"` 接口，以简短中文前缀开始思考；预算耗尽时注入中文结束提示，减少模型继续把分析草稿输出到正文。256/768 预算不变。

请求明确使用 `reasoning_format: "deepseek"` 分离思考与正文；前端兼容原始 think 标签和跨流式片段的标签边界。旧默认提示词自动升级，自定义提示词不在存储中被覆盖，语言规则仅在生成请求时附加。语言仍由模型生成，不能保证每个模型、每次采样都完全遵守；不通过删除英文文本伪造中文效果。

回归测试：`node --test tests/*.test.cjs`。已有本地服务运行时，可另执行 `node tests/local-thinking-smoke.cjs` 验证思考开关、预算结束和英文翻译。

## 安装步骤

### 已有模型：直接放在项目中

1. 把一个完整的 `.gguf` 文件放进本项目的 `models` 文件夹，文件名不限。
2. 双击根目录的 `Setup-AnanChrome.cmd` 配置一次（需要已经安装 llama.cpp；可复用之前的运行时配置）。
3. 在浏览器重新加载一次扩展，以后打开侧边栏会自动启动模型。

模型目录为空时暂时沿用之前的外部模型；放入 GGUF 后下次启动优先使用该文件。有多个主模型时会明确提示，不会随便选一个。需要指定文件时运行 `setup-project.ps1 -ModelPath '完整路径'`。正在运行的模型不会因文件变化被中断，切换权重在服务下次启动时生效。移动项目后需要重新配置一次。

如果提示“扩展未获授权”，在扩展管理页查看当前 ID，再运行 `setup-project.ps1 -ExtensionIds '实际扩展ID'`。无需卸载扩展或重新下载权重。单纯放置模型不能替代浏览器与本地运行时的注册连接。

### 1. 安装 Windows 本地运行时（仅首次）

普通用户双击：

```text
runtime\Install-AnanChrome.cmd
```

安装程序会下载并校验 llama.cpp CUDA 12.4 运行时和 Qwen3.5-9B Q4_K_M 模型，然后注册 Chrome/Edge Native Messaging。模型约 5.24 GiB，只下载一次。安装完成后，打开扩展会自动在后台启动模型，不再需要运行 BAT，也不会弹出命令行窗口。

`start-server.bat` 仅保留给开发者排查问题，不属于正式用户流程。

### 2. 安装扩展

- **Edge**：地址栏输入 `edge://extensions/` → 打开左下角「开发人员模式」→ 点「加载解压缩的扩展」→ 选择本文件夹。
- **Chrome**：地址栏输入 `chrome://extensions/` → 打开右上角「开发者模式」→ 点「加载已解压的扩展程序」→ 选择本文件夹。

### 3. 打开侧边栏

- 点击浏览器工具栏上的扩展图标，或
- 在任意页面右键 → 「打开 AI 侧边栏」。

侧边栏会自动完成“检测运行时 → 后台启动模型 → 等待模型就绪”：**绿 = 已连接，黄 = 正在加载，红 = 运行时缺失或模型启动失败**。

### 4. 联网搜索（可选）

点左上角菜单，再点菜单左下角“设置”，填入你的 Tavily API Key（在 <https://tavily.com> 注册，额度以服务方为准）。不填也能用对话和总结模式。

## 设置项说明

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 服务地址 | `http://127.0.0.1:8080` | llama-server 监听地址 |
| Temperature | `0.7` | 越高越发散 |
| Top P | `0.9` | 核采样 |
| 最大输出 Token | `2048` | 单次回答长度上限 |
| 思考 | 关 | 开启后自动在 256 / 768 token 预算之间选择 |
| 系统提示词 | 中文助手 | 定义 AI 角色 |
| Tavily API Key | 空 | 联网搜索用 |

设置修改后**实时生效**，无需重启扩展。

## 常见问题

**点图标没反应 / 侧边栏显示红点**
→ 首次使用请安装一次 Windows 本地运行时。已经安装时查看 `%LOCALAPPDATA%\AnanChrome\Logs` 中的日志；无需手动运行 `start-server.bat`。

**总结网页没内容 / 报错**
→ `chrome://`、`edge://`、扩展商店、PDF 阅读器等特殊页面无法提取正文，属正常限制。普通 `http/https` 网页都能总结，**无需刷新页面**（改为按需注入，安装前打开的页面也支持）。

**回答很慢**
→ 9B 模型比 4B 占用更多显存且生成速度更慢，但回答能力更强。开启“思考”后会先判断问题复杂度，再使用 256 或 768 个思考 token。

**搜索报错 401 / 429**
→ 检查 Tavily API Key 是否正确、免费额度是否用完。

**改了代码但没生效**
→ 到 `edge://extensions/` 点该扩展卡片上的「重新加载」（刷新图标）。
