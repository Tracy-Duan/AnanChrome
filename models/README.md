# 本地模型目录

把要使用的完整 `.gguf` 权重放在这个文件夹内（不要放在子文件夹）。推荐只保留一个主模型；`mmproj*.gguf` 投影文件不会被当作聊天模型。

第一次使用或移动整个项目后，双击项目根目录的 `Setup-AnanChrome.cmd` 配置一次。之后打开扩展会自动启动模型，不需要每天运行脚本。

- 只有一个主模型：自动选用，不要求固定文件名。
- 没有主模型：若之前配置的外部模型还存在，暂时继续使用它。
- 有多个主模型：不随机选择；请移走多余文件，或在配置脚本中用 `-ModelPath` 指定。
- 更换权重后，已经运行的服务不会被自动中断；新模型在服务下次启动时加载。

模型不会被打进扩展 ZIP，也不会提交到版本控制。请保留此文件夹的位置；浏览器扩展本身无法直接执行 GGUF，仍需要一次性注册本地运行时。
