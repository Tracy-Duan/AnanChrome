# AnanChrome Windows 整合包

包含浏览器扩展、llama.cpp b10630（含 CPU 与 CUDA 12.4 依赖）和 Windows 本地运行时。模型权重由设置页单独下载。

## 首次使用（只需配置一次）

1. **完整解压 ZIP** 到一个固定文件夹，不要在压缩软件内直接运行，也不要之后随意移动 `extension` 文件夹。
2. 双击 `Install-AnanChrome.cmd`。它将本地引擎复制到当前用户的应用目录并注册 Chrome / Edge 连接，不需要管理员权限，不会立即下载大模型。
3. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`），开启“开发者模式”，点“加载已解压的扩展程序”，选择解压目录中的 **extension** 文件夹。更新已有扩展时点“重新加载”，无需卸载。
4. 打开 AnanChrome，点击左上角菜单 → 左下角“设置” → **下载模型**。约 5.63 GB，下载完成自动校验并配置，无需移动权重。关闭设置页仍会下载；电脑休眠、断网或退出下载进程后，回到此处点击继续下载。
5. 返回侧边栏，首次模型加载稍等片刻。后续打开会自动启动本地模型，无需手动运行服务。

浏览器安全限制决定：仅加载扩展不能执行 ZIP 内的 EXE，也不能替你完成系统注册。因此不能承诺“只发一个 ZIP、零安装、立即聊天”。本包把全部运行程序合在一个 ZIP 中，尽量将首次配置缩减到上述步骤。

## 模型与设备

- 下载模型：HauhauCS/Qwen3.5-9B-Uncensored-HauhauCS-Aggressive 的 Q4_K_M 版本。
- 权重目录：`%LOCALAPPDATA%\AnanChrome\Models`；模型与不完整的续传文件不会被打包进扩展。
- 请准备至少约 8 GB 可用磁盘空间；如果更新旧模型，需额外保留旧权重占用空间。9B 模型需要较多内存/显存，低配置电脑不能保证流畅。
- CUDA 加速需要兼容的 NVIDIA 显卡及驱动；没有可用 CUDA 设备时引擎可使用 CPU，速度明显更慢。尚未对所有 Windows 硬件做兼容性验证。
- 不会打断已经运行的模型；下载新权重后若旧服务仍在运行，新权重会在该服务下次启动时使用。
- 手动下载是备用入口；手动下载的文件不会自动导入，可把完整权重放到上述 Models 目录，之后点击设置中的下载按钮进行校验和配置。

## 历史与隐私

历史对话保存在当前浏览器本地，菜单中可恢复、删除。每个会话最多记住三个网页，第四个替换最早的网页。新建对话不会删除旧聊天。无痕窗口不写入持久历史。普通对话、网页阅读不上传云端；下载会访问 Hugging Face，联网搜索会将搜索词发送给 Tavily。

## 排错

- 提示未检测到运行时：重新运行本包的安装入口，并刷新扩展。
- 下载中断：再次点击“下载模型”或“继续下载”，已完成的部分会尝试续传。
- 启动超时：确认设备有足够内存/显存，查看 `%LOCALAPPDATA%\AnanChrome\Logs`。
- 如果系统安全软件拦截，先确认 ZIP 来源可靠；此开发分发包尚未提供代码签名，不建议关闭安全软件。
- 清理运行时：可运行 `runtime\uninstall-runtime.ps1`；不会替你删除大模型文件。
